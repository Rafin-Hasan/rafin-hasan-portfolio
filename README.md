# Rafin Hasan — Minimalist Portfolio Website

An ultra-clean, modern, high-performance portfolio website built with **React**, **Vite**, and **Tailwind CSS**.

![Portfolio Preview](/public/profile.jpg)

## ✨ Features

- **Tailored Aesthetic**: Deep royal navy blue accents (`#1e3a8a`), slate surfaces, and glassmorphic micro-interactions matching high-end design aesthetics.
- **Performant & Lightweight**: Built with Vite and React for sub-second page loads and zero bloat.
- **Mobile First & Responsive**: Optimized typography and fluid layouts across mobile, tablet, and widescreen viewports.
- **Interactive Project Showcase**: Dynamic filtering and direct links to live repositories and demos.
- **Copy-to-Clipboard**: One-click email copying with toast notification state.
- **Clean DevOps & Vercel Ready**: Preconfigured with `vercel.json` for SPA routing and instant CI/CD deployment.

## 🛠️ Tech Stack

- **Framework**: [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) + PostCSS
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: [Vercel](https://vercel.com/)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or pnpm

### Installation

```bash
git clone https://github.com/Rafin-Hasan/rafin-hasan-portfolio.git
cd rafin-hasan-portfolio
npm install
```

### Local Development

```bash
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
